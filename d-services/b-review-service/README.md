# b-review-service

This is the Review Service submodule for The Hobbit Online Store.

## Overview
- Spring Boot microservice for review management
- Java 21, Lombok, MapStruct, Spring Boot

## How to run

```sh
./gradlew :d-services:b-review-service:bootRun
```

## Directory Structure
- `src/main/java/chanhnguyen/hoppy/review/` - Main application code
- `src/main/resources/` - Configuration files

## Features
- Review API endpoints (to be implemented)
- Integration with core and API modules
